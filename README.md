# AhmiXen — Next.js

Live AI masterclass landing page built with Next.js App Router, React, TypeScript, and Tailwind CSS.

## Scripts

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run start
npm run lint
```

## Stack

- Next.js (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
